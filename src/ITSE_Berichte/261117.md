## Übung  3.2 (SHA256 Shell)

Der Hex-wert der Datei `goethe.txt (https://www.franzmatejka.at/htl/doc/ITSI_2/05_hashing_encoding/data/goethe.txt)` ist:

```
lemuel.butuman@htlsrv-coding-01-berger:~/2026-3AHITS-SEW$ openssl SHA256 goethe.txt 
SHA2-256(goethe.txt)= a911a35ff92bcd4250c063a0547dae3f1ba2b839eaf12b64c955cf3ff7e570e0
```

`openssl SHA256` gibt die Datei in einem Hex wert Herraus.
