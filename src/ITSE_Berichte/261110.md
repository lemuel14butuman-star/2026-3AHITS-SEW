Um den Bridged mode einzustellen musst du:
 
1. Die Maschinen herunterfahren (Kali,Metasploitable)
2. VMWare öffnen
3. Kali-Linux auswählen 
4. Auf edit virtual machine
5. Network adapter auswählen
6. Bridged auswählen 
7. Und dan auf Configure Adapter und auf Intl(R)
7. Connect at power muss auch an sein 
8. Jetzt klicke auf ok 
9. Das machst du bei Kali und Metasploitable

## Test versuche in Bridged mode
1. Von Kali, Metasploitable pingen. Geht(Ja/Nein): Ja 
2. Von Metasploitable, Kali pingen. Geht(Ja/Nein): Ja
3. Von Host-System beide VMs pingen. Geht(Ja/Nein): Ja
4. Von Kali, Host-System pingen. Geht(Ja/Nein): Nein
5. von Kali, einen ping auf ein anderes Kali-System auf einem anderen Rechner. Geht(Ja/Nein): Ja

## Übung_2_2 Dateitransfer per Webserver Metasploitable -> Kali
 
Datei anlegen mit `echo > Dateinname` und inhalt mit echo >> Daeiname Inhalt
 
Du musst herausfindne welcher Webserver auf Metasploitable läuft und in welchem verzeichni dieser die Datei ablegt.
 
Mit `ps` kann man prüfen ob der Server auch läuft und mit `more`kann man die ausgabe stopen.
Mit `sudo netstat -tlpn` bekommst du hilfreiche informationen
